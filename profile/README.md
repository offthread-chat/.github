Offthread offers AI chat without an account, browser-local saved history, and a temporary chat mode. Its redaction tools replace detected sensitive values with placeholders in your browser before sending a message. AI responses are generated by external providers; redaction can miss information. Read the [privacy policy](https://offthread.chat/privacy) for processing details.

Here we publish code and measurements from our work on browser-local detection, so other developers can inspect the tradeoffs and reproduce the experiments.

## Browser PII Lab

**Run small detection models in your browser. See what they catch, miss, and cost to run.**

[Browser PII Lab](https://github.com/offthread-chat/browser-pii-lab) compares Gravitee BERT small PII, BERT base NER, and multilingual DistilBERT with regex and hybrid detection. The demo uses plain HTML, CSS, JavaScript, and a WASM model worker.

### Read the measurements in context

Long inputs are split into model-sized chunks; these models do not have a 100K context window. Throughput measures **input processing**, and first-chunk latency is distinct from generative time to first token. CPU and memory measurements cover the isolated Chrome processes, including browser overhead.

The published runs use one machine and synthetic data. They are a reproducible starting point, not a universal model ranking or a privacy guarantee. The results page includes an interactive view you can run locally.
